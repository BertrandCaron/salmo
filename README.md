# Salmo game

MS-DOS game by Myriad, produced in 1990.

This repository contains a broken image ('salmo.img') where the 21st sector could not be read. The second image ('salmo_fixed.img') is an attempt to recreate this missing sector. The folder called 'initial_logical_copy' contains the files read on the first image, plus incomplete sixteen files that were read during the first access to the floppy with a USB floppy drive.

The method was described in this blog post in French: [Restaurer un système de fichiers FAT12 altéré](https://digipres.fr/archives/468).
