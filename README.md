# Salmo game

MS-DOS game by Myriad, produced in 1990.

This repository contains a broken image ('salmo.img') where the 21st sector could not be read. The second image ('salmo_fixed.img') is an attempt to recreate this missing sector.

The method was described in this blog post in French: [Restaurer une table d'allocation de fichiers (FAT)](https://digipres.fr/).
